
# Placement Preparation Platform 🚀

A comprehensive **Placement Preparation Web Application** built using **React.js** that helps students prepare effectively for campus placements.  
The platform provides **AI-based chat support, mock test analysis, personalized guidance**, and other essential preparation tools.  
All user data is managed efficiently using **Local Storage**, ensuring fast access without a backend.

---

## 🧠 Features

- 🤖 **AI Chat Assistance**
  - Interactive AI chat to answer placement-related questions
  - Guidance on interview preparation, aptitude, DSA, and HR rounds

- 📝 **Mock Test System**
  - Practice tests for aptitude, technical, and logical reasoning
  - Timer-based tests to simulate real exam conditions

- 📊 **Mock Test Analysis**
  - Detailed performance analysis after each test
  - Score tracking, accuracy, and topic-wise feedback

- 🎯 **Placement Guidance**
  - Roadmaps for placement preparation
  - Tips for resume building, interview rounds, and company-specific prep

- 💾 **Local Storage Data Handling**
  - Stores user progress, test results, and preferences
  - No backend required, ensuring faster performance

- 📱 **Responsive UI**
  - Works smoothly on desktop, tablet, and mobile devices

## 🚀 How to Run the Project

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/placement-prep-project.git


2. Navigate to the project directory

   ```bash
   cd placement-prep-project
   ```

3. Install dependencies

   ```bash
   npm install
   ```

4. Start the development server

   ```bash
   npm start
   ```
